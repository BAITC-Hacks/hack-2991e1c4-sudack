# Career Quest frontend

Веб-интерфейс для кейса HackAlem AI / Halyk Bank: профиль сотрудника, объяснимые рекомендации, изменение прогресса после активности и HR-аналитика.

## Запуск

Требуется Node.js 20.9+.

```powershell
npm install
npm run dev
```

Откройте `http://localhost:3000`. По умолчанию приложение работает на синтетическом датасете из `data/` (200 сотрудников, 40 событий, 60 навыков и 2743 записи истории). Для демонстрации удобно выбрать `E0028`; можно открыть любого сотрудника из списка. HR-роль доступна на том же экране входа. В демо-режиме выбор роли не является серверной авторизацией.

## Сценарий проверки

1. Войти как сотрудник, выбрать профиль и открыть `/me`.
2. Увидеть роль, грейд, требования следующего грейда, навыки и историю.
3. Раскрыть «Как рассчитано» в рекомендации: там приведены факторы, данные истории и формула оценки.
4. Нажать «Отметить выполненной». Уровни навыков, готовность, история и список рекомендаций обновятся без перезагрузки. Изменения демо сохраняются в `localStorage` этого браузера.
5. Войти как HR, открыть `/hr`: топ разрывов, сотрудников без шага и таблицу участия.
6. Через «Импорт данных» добавить `employees.json` и/или `activity_history.csv` в формате кита. Демо проверяет идентификаторы и ссылки, показывает отчёт и обновляет HR-срез. Повторная загрузка записей с тем же `record_id` не дублирует историю.

## Подключение API

Создайте `.env.local`:

```env
NEXT_PUBLIC_USE_MOCKS=false
NEXT_PUBLIC_API_URL=http://localhost:8080
```

Перезапустите frontend. На экране входа появится поле для тестового bearer-токена. Клиент ожидает маршруты Go из `backend/BACKEND.md`: `GET /api/v1/employees/:id`, `GET /api/v1/employees/:id/recommendations`, `POST /api/v1/employees/:id/events/:event_id/completions`, `GET /api/v1/hr/overview`, `POST /api/v1/imports`. Сейчас Go-репозиторий содержит контракт, но HTTP-маршруты ещё не реализованы; реальное подключение можно проверить после их появления. Токен в режиме API хранится в `sessionStorage` и передаётся в `Authorization`. Права доступа должен проверять сервер.

## Логика демо

Моковые рекомендации используют требования следующего грейда, фактический разрыв и критичность навыка, эффект активности и историю похожих событий. Недоступные, обязательные, уже завершённые и не дающие прироста события исключаются. Скоринг и объяснения в демо детерминированы; бейдж указывает «Проверенный расчёт», а не AI. Python AI-сервис находится отдельно в `../sudack-ai` и должен вызываться Go API.

Проверка сборки: `npm run lint`, `npm run build`.
